# Programación estructurada con Python

Material del curso «Programación estructurada con Python» de NonLinear Academy. Son seis cuadernos de Jupyter, pensados para abrirse directamente en Google Colab.

**Dirigido a:** Estudiantes que empiezan a programar y quieren aprender lógica, condicionales y ciclos con Python.

## Cuadernos

| Cuaderno | Descripción | Abrir en Colab |
|---|---|---|
| `programacion_estructurada.ipynb` | Introducción a la programación estructurada. | [Abrir](https://colab.research.google.com/github/NonLinear-Academy/programacion-estructurada/blob/main/programacion_estructurada.ipynb) |
| `logica_matematica.ipynb` | Lógica matemática aplicada en Python. | [Abrir](https://colab.research.google.com/github/NonLinear-Academy/programacion-estructurada/blob/main/logica_matematica.ipynb) |
| `operadores_comparacion.ipynb` | Operadores de comparación. | [Abrir](https://colab.research.google.com/github/NonLinear-Academy/programacion-estructurada/blob/main/operadores_comparacion.ipynb) |
| `operadores_logicos.ipynb` | Operadores lógicos. | [Abrir](https://colab.research.google.com/github/NonLinear-Academy/programacion-estructurada/blob/main/operadores_logicos.ipynb) |
| `sentencias_condicionales.ipynb` | Sentencias condicionales. | [Abrir](https://colab.research.google.com/github/NonLinear-Academy/programacion-estructurada/blob/main/sentencias_condicionales.ipynb) |
| `ciclos.ipynb` | Ciclos. | [Abrir](https://colab.research.google.com/github/NonLinear-Academy/programacion-estructurada/blob/main/ciclos.ipynb) |

## Cómo usar este material

1. Abre cualquier cuaderno con el enlace de Colab de la tabla anterior; no necesitas instalar nada.
2. Para trabajar en tu computadora: clona el repositorio y abre los cuadernos con Jupyter Notebook, JupyterLab o Visual Studio Code.
